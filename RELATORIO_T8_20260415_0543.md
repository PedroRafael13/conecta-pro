## Diagnóstico real (CIC confirmado)

### Bug A — Fluxo de Caixa 404
**Causa raiz:** `api-client.ts` continha regex de deduplicação de paths:
```js
config.url = config.url.replace(/\/([^\/]+)\/\1(?:\/|$)/, '/$1');
```
Esta regex transformava `/cashflow/cashflow/projection` → `/cashflow/projection`,
e `/cashflow/projection` tem `condominio_id: UUID` **obrigatório** → 422.
Adicionalmente, endpoints dashboard/projection/ai tinham condominio_id required.

**Fix:** Regex desativada para paths `/cashflow/cashflow/` (intencional no Orval).
Endpoints projection + dashboard + ai/risks + ai/opportunities → condominio_id Optional.

### Bug B — Custos crash "Algo deu errado"
**Causa raiz:** Erro de runtime JavaScript — `.map()` em dados sem optional chaining,
incompatibilidade entre formato da API e tipos esperados pelo componente.

**Fix:** `custos/page.tsx` reescrito do zero com:
- `fetchWithAuth()` direto (sem hook Orval intermediário)
- Optional chaining em todos os accessors: `?.`, `?? []`, `?? 0`
- Error boundary explícito com mensagem informativa
- 0 mocks | TypeScript: 0 erros

### Bug C — 422 persistente em contas-pagar/receber
**Causa raiz:** `payable_controller.py` e `receivable_controller.py` tinham guards
`if not condominio_id: raise HTTPException(422)` que persistiam após fix do Query(...).

**Fix:** Guards removidos. Varredura completa: 0 residuais Query(...) obrigatório.

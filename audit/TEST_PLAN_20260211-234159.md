# TEST_PLAN (20260211-234159)

## Backend (FastAPI)

**Unit + integration**
- Comando: `cd /opt/conecta-pro/backend && ./venv/bin/pytest -q`
- Escopo: `tests/`, incluindo `_integration` e `_integration/e2e`

**SAST/lint/typecheck**
- `cd /opt/conecta-pro/backend && ruff check modules core api`
- `cd /opt/conecta-pro/backend && mypy modules`

**Modulos (amostra por dominio)**
- CRM: `tests/modules/crm/` + `tests/test_client_*` + `tests/test_lead_*`
- Financeiro: `tests/domains/financial/` + `tests/test_*financial*`
- Operacional: `tests/operations/` + `tests/domains/operacional/`
- RH: `tests/test_time_tracking_*` + `tests/test_payroll_*`
- LGPD/Security: `tests/core/security/` + `tests/modules/lgpd/`

## Frontend (Next.js)

**Unit/Integration (Vitest)**
- `cd /opt/conecta-pro/frontend && npm run test:run`

**Lint/Typecheck**
- `cd /opt/conecta-pro/frontend && npm run lint`
- `cd /opt/conecta-pro/frontend && npm run type-check`

**E2E (Playwright)**
- Pre-req: app disponivel e `BASE_URL` apontando para ambiente de teste
- Listar: `cd /opt/conecta-pro/frontend && npm run test:e2e -- --list`
- Executar: `cd /opt/conecta-pro/frontend && BASE_URL=http://localhost:3000 npm run test:e2e`

## Observacoes
- E2E usa auth setup (`frontend/e2e/auth.setup.ts`) e storageState em `frontend/e2e/.auth/`
- Evitar rodar E2E contra producao real; usar ambiente isolado

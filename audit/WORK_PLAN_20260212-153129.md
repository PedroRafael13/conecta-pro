# WORK PLAN - OPERACAO COM CLAUDE CODE TEAM (OPUS 4.6)

## Objetivo
Executar correcoes com multiagentes em lotes pequenos, sob supervisao e auditoria continua.

## Modelo de operacao
1. Agente Triage (le backlog e quebra em tarefas atomicas).
2. Agente Security (P0/P1 de segredos, OAuth e dependencias).
3. Agente Backend Quality (lint/test/security backend).
4. Agente Frontend Quality (lint/typecheck/build/test frontend).
5. Agente Validation (reexecuta testes/scans e valida evidencias).
6. Supervisor (voce + eu) aprovando gate por gate.

## Gates obrigatorios por PR
- Gate A: sem segredo no diff/repo.
- Gate B: lint+typecheck verdes.
- Gate C: testes unitarios/integracao verdes.
- Gate D: scans seguranca sem regressao.
- Gate E: evidencia consolidada em markdown.

## Cadencia
- Lote 1: P0 completo.
- Lote 2: P1 seguranca.
- Lote 3: qualidade frontend/backend.
- Lote 4: E2E e hardening.

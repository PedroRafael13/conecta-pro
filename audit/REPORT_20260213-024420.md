## Findings (com severidade)

### P0
1) Segredos versionados / historico com credenciais
- Impacto: risco direto de vazamento de chaves/certificados; bloqueia producao com dados reais.
- Evidencia:
  - Presenca de artefatos sensiveis rastreados: certs/conecta_certificado.p12, frontend/.env.production.
  - Remocoes locais de credentials/ indicam segredos historicos ainda no git.
- Recomendacao: rotacao imediata das credenciais + limpeza do historico git (acao destrutiva com aprovacao explicita).
- Criterio de aceite: nenhum segredo ou certificado sensivel em git ls-files e historico limpo (confirmado por varredura).

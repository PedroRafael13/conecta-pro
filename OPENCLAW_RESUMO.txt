🎯 SOLUÇÃO: OPENCLAW

O OpenClaw é um agente de IA que trabalha como um engenheiro de software
sênior, 24 horas por dia, 7 dias por semana, melhorando continuamente o
Conecta PRO.

✅ O que ele FAZ:
  • Resolve TODOs e FIXMEs automaticamente
  • Aumenta cobertura de testes (meta: 85%)
  • Corrige bugs e vulnerabilidades
  • Implementa endpoints faltantes
  • Melhora qualidade do código (lint, types)
  • Faz commits e push no Git
  • Envia relatórios diários (Discord/Slack)

✅ Onde ele TRABALHA:
  • Ambiente STAGING separado (não afeta produção)
  • Banco de dados próprio (conecta_pro_staging)
  • Branch 'staging' no Git

✅ O que ele NÃO faz:
  • Não acessa produção (read-only para monitoring)
  • Não modifica dados de clientes reais
  • Não faz deploy sem aprovação
  • Não expõe credenciais

OPÇÃO 1: SCRIPT AUTOMÁTICO (Recomendado)
─────────────────────────────────────────────────────────────────────────

1. Obter API Key do Claude:
   → https://console.anthropic.com/
   → Create Key
   → Copiar: sk-ant-api03-...

2. Configurar .env:
   nano .env

   # Adicionar:
   ANTHROPIC_API_KEY=sk-ant-api03-SUA_KEY_AQUI
   ANTHROPIC_MODEL=claude-3-5-sonnet-20241022
   OPENCLAW_ENABLED=true
   DISCORD_WEBHOOK=https://discord.com/api/webhooks/... (opcional)

3. Executar setup:
   bash scripts/openclaw/setup-openclaw.sh

4. Acompanhar:
   docker logs -f openclaw-agent
